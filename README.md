# Network Infrastructure Labs

This repository contains my daily lab files, topology configurations, and technical notes as I work through my network engineering studies and the Jeremy's IT Lab CCNA curriculum.

The goal of this repo is to track my consistency, document my command configurations, and provide step-by-step instructions to help anyone practicing the same network topologies.

---

## Infrastructure Technologies Covered

**Routing Architecture:**  Static Routing, Inter-VLAN Routing (ROAS), Single-Area/Multi-Area OSPF, EIGRP
**Switching & Layer 2 Stability:** VLANs, 802.1Q Trunking, Spanning Tree Protocol (STP/RSTP), EtherChannel (LACP/PAgP)
**Network Security:** Access Control Lists (ACLs), NAT/PAT, Port Security, DHCP Snooping, Dynamic ARP Inspection (DAI)
**Core IP Services:** DHCP, Network Time Protocol (NTP), CoreDNS, SSH/Telnet Secure Management

---

## Repository Structure

The project is organized sequentially by curriculum blocks:
`CCNA Labs/` — Houses the individual daily network labs.
Each lab sub-folder contains the raw simulation topology files (`.pkt` or `.gns3`) along with a dedicated `README.md` breaking down the specific CLI commands, verification steps, and operational gotchas.

## Getting Started with These Labs

1. **Clone the Repository
2. **Navigate to a Lab:**  Browse to any specific day folder inside the `CCNA Labs` directory.
3. **Execute the Simulation:**  Open the corresponding lab file in Cisco Packet Tracer or GNS3 and review the local `README.md` configuration notebook to run the verification steps.
